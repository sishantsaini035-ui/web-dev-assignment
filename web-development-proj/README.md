##  Getting Started

To preview the projects locally:

1. Open the folder in your browser, or run a local server.
2. Navigate to any HTML file in the project folders.
3. Edit the HTML/CSS files to experiment with different layouts and styles.

Example:

```bash
cd "web lab"
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
